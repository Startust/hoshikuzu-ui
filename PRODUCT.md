# Product

## Register

product

## Users

Hoshikuzu UI is for one maker and the small tools they build: the hoshikuzu
star index and its utilities, desktop apps like note-taker, and operational
tools like review-pilot. People using those products are makers, players and
owner-operators who want calm, precise instruments rather than marketing
surfaces.

The kit's direct users are developers (often coding agents) assembling those
products with shadcn. They need components that look right by default in both
atlas modes, so that a new tool belongs to the same observatory without design
work.

## Product Purpose

Give every Hoshikuzu product one shared visual language: shadcn components
restyled into the quiet archival star atlas, plus the atlas-specific pieces
(star panel, measurements, status dots, data lists, timelines, mode switch)
that the source projects each built by hand.

Success means a new tool can be scaffolded with `shadcn init -b base`, add the
theme and components from this registry, and already feel like part of
hoshikuzu, in night and archive mode, without page-level CSS.

## Brand Personality

Quiet, archival, celestial. Restrained, attentive, slightly mysterious and
precise, with the intimacy of a personal notebook.

## Anti-references

- Generic SaaS dashboards: oversized hero metrics, repeated feature cards,
  saturated pill filters.
- Neon sci-fi HUDs, cyberpunk control panels, game menus.
- Glassmorphism, bokeh, purple-blue gradient washes, decorative glow.
- Thick colored side stripes as selection markers.

## Design Principles

1. **Annotate, do not decorate.**
2. **Silence is structure.**
3. **Make motion feel inevitable.**
4. **Keep tools usable.**
5. **Let stars own the light.**

## Accessibility & Inclusion

WCAG AA contrast in both modes, including muted text on raised surfaces.
Keyboard-reachable controls with visible, soft focus rings. Status never
relies on color alone. Reduced motion collapses all transitions and
animations. Touch targets of at least 44px on mobile navigation and primary
actions.
